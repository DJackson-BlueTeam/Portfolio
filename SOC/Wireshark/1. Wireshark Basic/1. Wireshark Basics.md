
WireShark Basics
-----
Wireshark is one of the most defined traffic analyzers used.  

- Detecting and troubleshooting network problems, such as network load failure points and congestion.  
- Detecting security anomalies, such as rogue hosts, abnormal port usage, and suspicious traffic/ 
- Investigating and learning protocol details, such as responses codes and payload data. 
    
**pcap (Packet Capture)** 
- Is the standard file format used by Wireshark and other network analyzers to store data packets captured from a network 
- To be able to analyze packages, you must upload a pcap (Packet Capture) file to Wireshark.

3. What is the TTL value?  
     - TTL (Time To  Live): is a field found within the IPv4 (Internet Protocol version 4) header of a packet. It prevent packets from circulating for long periods of time on a network in the event of a routing loop.
     - [What Is Time to Live (TTL)? | IBM](https://www.ibm.com/think/topics/time-to-live)
- You can find the Time To Live in the “Internet Protocol Version” section.

Answer: 47 

4. What is the TCP payload size?  
    - TCP (Transmission Control Protocol): a connection oriented protocol at the Transport Layer (Layer 4) of the OSI model. This act as protection of the data while being sent through the network in the same order when it is delivered and ensure there is no errors.
    - TCP Payload Size: is the actual amount of application-layer data carried within a single TCP segment. 
    - `TCP Payload Size=Total IP Length−(IP Header Length+TCP Header Length)`
- You will be able to find the TCP payload size in the “Transmission Control Protocol” section.  
- It will be displayed as “Len:123” or in the “[TCP Segment Len:123]” 
    [[Maximum Packet Size for a TCP Connection | Baeldung on Computer Science](https://www.baeldung.com/cs/tcp-max-packet-size)
	
	![alt text](https://github.com/DJackson-BlueTeam/Portfolio/blob/250ad75b2b62b68023cb74f36214da53be0b3cbd/SOC/Wireshark/1.%20Wireshark%20Basic/Basic%20Img/WS%20TCP%20Payload.png)

Answer: 424 

5. What is the e-tag value? 
- You will be able to find the e-tag value in the “Hypertext Transfer Protocol” section and you will see “ETAG:” 
	- Entity Tag (Application Layer 7 of OSI Model): is an HTTP response header used for web cache validation. It acts as a unique identifier for a specific version of a resource - such as a image or a webpage - found on a server.

  - [[ETag header - HTTP | MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/ETag)]
