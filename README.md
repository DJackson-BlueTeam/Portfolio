## Technical Projects & Labs (TryHackMe: SOC Level 1 Path)

This section highlights the hands-on labs and projects undertaken to build and demonstrate my SOC analyst capabilities. These experiences, primarily from the TryHackMe SOC Level 1 Path, have provided me with practical exposure to various security operations tasks.

### Lab/Capstone 1: Monitoring and Investigating Malicious Activity
*   **Description:** Completed hands-on labs focused on actively monitoring systems and investigating suspicious or malicious activities. This involved understanding common attack vectors and recognizing indicators of compromise (IOCs).
*   **Key Learnings:**
    *   Proactive threat detection techniques.
    *   Identification of anomalous behavior in network traffic and system logs.
    *   Initial incident triage and assessment.

### Lab/Capstone 2: Network Traffic Analysis for C2 and Data Exfiltration
*   **Description:** Performed detailed analysis of network traffic captures using tools like Wireshark. The objective was to identify Command and Control (C2) communications and detect instances of data exfiltration.
*   **Key Learnings:**
    *   Deep packet inspection (DPI) and protocol analysis.
    *   Recognizing C2 patterns and data leakage signatures.
    *   Using network forensics to trace malicious activity.

### Lab/Capstone 3: SIEM Tool Utilization for Security Breach Identification
*   **Description:** Utilized Security Information and Event Management (SIEM) tools (e.g., Splunk, ELK) to correlate logs from various sources. The focus was on identifying potential security breaches by analyzing aggregated security events and alerts.
*   **Key Learnings:**
    *   Configuring and querying SIEM solutions.
    *   Developing correlation rules to detect complex attack scenarios.
    *   Generating reports and dashboards for security posture visualization.

### Lab/Capstone 4: Incident Response Procedures and Threat Simulation
*   **Description:** Practiced incident response procedures, including the critical steps of containment and reporting of simulated threats. This involved working through various incident scenarios to understand the lifecycle of a security incident.
*   **Key Learnings:**
    *   Executing incident response playbooks.
    *   Implementing containment strategies to limit the impact of a breach.
    *   Documenting incidents and preparing clear, concise reports for stakeholders.
